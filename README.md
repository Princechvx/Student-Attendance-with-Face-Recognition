Student Attendance with Face Recognition
An AI-powered attendance system that uses face recognition to automate student attendance. The system captures images via a webcam, detects and verifies faces using OpenCV and face_recognition, and logs attendance in an Excel file. It features a Tkinter-based GUI for easy interaction.

Technologies Used
Python (OpenCV, face_recognition, Pandas, Tkinter)
Database: Excel (Expandable to cloud storage)
Features
✅ Real-time face detection & recognition
✅ Automated attendance logging
✅ User-friendly GUI
✅ Scalable for schools & offices 

Future Enhancements
Cloud-based data storage
Mobile app version
Enhanced recognition accuracy with deep learning
